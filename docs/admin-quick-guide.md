# TOWEB Admin Quick Guide

Panduan cepat operasional harian Content Management System (CMS) TOWEB untuk Jurusan Teknik Otomotif SMK Negeri 1 Bangsri.

## Alur Kerja Sehari-hari
**Login** → Buka URL `/admin` dan masukkan Email & Password
**Dashboard** → Halaman depan panel kontrol
**Pilih Menu Navigasi** → (Misal: *Berita*, *Galeri*, atau *Lowongan*)
**Manage Konten** → *Create* / *Edit* / *Delete*
**Update Tampilan** → *(Website terupdate secara otomatis dan langsung)*
**Logout** → Pilih ikon profil di kanan atas, lalu klik `Sign out`

## Quick Reference Table
| Kebutuhan / Aksi | Menu di Sidebar Kiri | Deskripsi |
|---|---|---|
| **Ubah Identitas Website (Logo, Teks Utama, Visi, Misi)** | `Sistem` > `Pengaturan Web` | Merupakan halaman tunggal untuk merubah identitas dasar, SEO, dan sosial media. |
| **Tambah Berita Baru** | `Posts` | Publikasikan berita kegiatan, kunjungan, atau artikel pendidikan. (Gunakan status *Published*). |
| **Kategori Berita** | `Categories` | Atur pengelompokan berita. |
| **Tambah Pengumuman** | `Announcements` | Publikasi pengumuman kilat. (Gunakan status *Active*). |
| **Tambah Guru / Staf** | `Teachers` | Atur direktori tenaga pendidik. Gunakan *Active* agar tampil di website. Matikan (uncheck) jika ingin menyembunyikan tanpa dihapus. |
| **Tambah Prestasi Siswa** | `Achievements` | Input penghargaan atau capaian medali jurusan. |
| **Tambah Album Galeri** | `GalleryAlbums` | Wadah utama untuk koleksi foto. |
| **Upload Foto Galeri** | `GalleryItems` | Di dalam tabel ini, upload foto dan tautkan ke `Album` yang sudah dibuat. |
| **Tambah Lowongan Kerja (BKK)** | `JobVacancies` | Publikasi loker terbaru dari Mitra Industri. Ganti status menjadi *Closed* bila pendaftaran sudah ditutup. |
| **Upload Dokumen (PDF, dll)** | `Downloads` | Sediakan dokumen SOP/modul. Pastikan memilih `Category` yang relevan. |

## ⚠️ Security Checklist
1. **Logout setelah selesai:** Selalu sign out jika menggunakan komputer fasilitas bersama (mis. di Lab Komputer).
2. **Data Bersifat Destruktif:** Tindakan menekan tombol `Delete` akan **secara permanen** menghapus record berserta dengan **Fisik File Gambar/Dokumen** yang terkait dari server. Gunakan fitur tombol nonaktif (seperti mengubah *Published* menjadi *Draft*, atau *Active* menjadi *Inactive*) jika Anda hanya ingin menyembunyikannya dari pengunjung.
3. **Password Aman:** Jangan pernah membagikan password admin Anda kepada siapapun. CMS ini dikendalikan oleh akses tunggal.
