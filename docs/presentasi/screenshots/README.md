2. **Slide Demo Fitur:** Gunakan tangkapan layar form kontak (`15_hubungi_kami_kontak.png`), tracer study (`10_tracer_study_alumni.png`), atau bursa kerja (`09_lowongan_karir_bkk.png`) saat menjelaskan fitur unggulan sistem pada Poin 2 dan Poin 3.
